# 年金合同备案审核看板

> 面向江西省企业年金/职业年金基金管理合同备案的网页版可视化审核辅助工具。

## 功能简介

- **导入数据**：点击右上角“导入数据”，选择合同备案材料文件夹，自动解析 `.docx`、`.pdf`、`.txt` 等文件。
- **自动审核**：按照年金合同备案审核要点清单逐项逐条生成审核结果与意见。
- **可视化看板**：展示材料统计、结论分布、各组审核情况、建议结论及风险等级汇总。
- **清除数据**：一键清空已导入数据及审核结果。
- **导出审核意见**：将审核结果导出为 Excel（.xlsx），便于存档与反馈。
- **本地使用**：纯前端实现，数据不上传服务器，支持本地浏览器直接打开或部署到 GitHub Pages。

## 使用方式

### 方式一：本地直接打开

1. 下载或克隆本仓库到本地。
2. 双击打开 `index.html`。
3. 点击右上角“导入数据”，选择存放合同备案材料的文件夹即可。

### 方式二：部署到 GitHub Pages

1. 将本项目推送到 GitHub 仓库。
2. 进入仓库 **Settings → Pages**，选择 `main` 分支及 `/(root)` 目录。
3. 保存后访问 GitHub Pages 链接，处室内部人员即可通过浏览器使用。

## 审核要点清单

审核规则围绕以下 9 个维度展开，可在 `js/auditRules.js` 中继续扩展：

| 维度 | 名称 | 说明 |
|------|------|------|
| A | 报送资料清单 | 材料齐全性、齐整性、签章真实性 |
| B | 合同期限 | 合同期限、生效与终止条款 |
| C | 合同唯一有效性 | 唯一性、与原合同衔接 |
| D | 业绩基准 | 业绩比较基准及调整机制 |
| E | 费率与费用结构 | 管理费、托管费及费率上限 |
| F | 考核与淘汰 | 投资管理人考核与淘汰机制 |
| G | 效力与空档期 | 合同效力、空档期责任安排 |
| H | 主体资格与管理人设置 | 管理人资格、职责边界 |
| I | 江西省地方要求 | 社保经办机构报备、信息披露 |

## 技术说明

- 纯静态网页，无需后端服务。
- 使用浏览器 `File API` 及 `webkitdirectory` 实现文件夹选择。
- 文本解析依赖开源库：`mammoth.js`（docx）、`PDF.js`（pdf）。
- 图表使用 `ECharts`，导出使用 `SheetJS`。
- 审核结果保存在浏览器本地存储（localStorage），关闭页面后再次打开可恢复。

## 注意事项

- 当前审核为基于关键词与规则的自动辅助审查，结论仅供参考，最终备案意见仍需人工复核。
- 扫描版 PDF 或图片文件无法直接提取文字，建议提供可搜索文本的 PDF 或 Word 文档。
- 如需扩展审核规则或调整风险等级，请编辑 `js/auditRules.js`。
